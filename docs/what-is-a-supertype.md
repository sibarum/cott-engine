What is a supertype?
===

Traction is an example of a "supertype." A supertype is a type that you subtract from rather than build on.
It's a bit nuanced, but once you understand it, it diffuses many of the common objections with this kind
of construction.

### No Hierarchy

Using traction, I still annotate the domains and ranges of functions and variables as it becomes relevant -
that part doesn't change. What does change is the carrier I work with, and how it doesn't have a hierarchy,
and it doesn't have one single set of rules in every context. That will make most mathematicians cringe,
but it's actually one of the greatest strengths of traction. Let me explain.

Traction has a concept of "universal invariance" - the kind of assumptions you can make about equality that must hold,
otherwise the algebra breaks down or loses it capabilities.

Being able to multiply both sides of an equation by the same value without breaking equality is only
safe if every value has a reciprocal. For example, if zero didn't have a reciprocal, you wouldn't be able
to do this with zero. Indeed, classically, this would erase the entire equation!

Using any operation on a variable assumes the operation is defined for any possible value the variable could take.
If your operation isn't defined for some value, your math completely breaks down, and from this there is no recovery.
I see this as an enormous failure of the mathematics community: that information-conservation is the most
reliable observation about the known universe we've ever made, and yet we're describing physics using a carrier
that violates thermodynamics. No wonder we don't have a unifying theory yet!

I digress. Long story short: Instead of starting with a small type and adding stuff to it piece by piece,
traction strives to encompass everything that numbers can possibly be used for, using the fewest axioms possible,
the fewest identities possible, and the fewest definitions possible. It's supposed to be advanced-alien-race-
teaches-mathematics-to-humans "type shit".
